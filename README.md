# Usage

## Installation

1. Download the latest release
2. Extract the archive using password `2026`
3. Run the companion as Administrator
4. Launch Apex Legends
5. Press INSERT to open the menu

## Combat

1. Open the **Combat** tab
2. Enable **Enhanced Aim** and set hotkey
3. Adjust FOV and smoothness
4. Enable **Auto Fire** if needed
5. Toggle **Recoil Control** and **Accuracy Boost**

## Visuals

1. Open the **Visuals** tab
2. Enable **Visual Awareness** for players
3. Toggle **Full Map Visibility** and **Health Bars**
4. Enable **Skeleton View** if needed
5. Set max distance

## Movement

1. Open the **Movement** tab
2. Enable **Movement Boost** and set multiplier
3. Enable **Perfect Glide** for enhanced glides
4. Toggle **Auto Hop** and **Fall Protection**

## Loot

1. Open the **Loot** tab
2. Enable **Loot Detection** for all items
3. Enable **Rare Loot Alert** for rare/legendary
4. Toggle **Weapon Detection** and **Ammo Detection**
5. Enable **Death Box Detection**

## Config

1. Open the **Config** tab
2. Click **Save** to store current settings
3. Click **Load** to restore a profile
4. Use **Streamproof** to hide overlay
